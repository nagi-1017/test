# プロンプト: Pin画像デザインブリーフの作成

## 用途
デザイナー/画像生成AIに渡すPin画像の指示書を作成する。

## プロンプト本文

```
あなたはPinterestマーケティングに強いビジュアルデザイナーです。
以下の記事情報を元に、Pin画像のデザインブリーフを3パターン作成してください。

【記事タイトル】: {タイトル}
【記事要約】: {要約}
【ターゲット読者】: {ペルソナ}
【ブランドカラー/トーン】: {00_shared/brand_guidelines.md を参照}

各パターンについて以下を出力してください。
1. デザインコンセプト（例: ライフスタイル訴求型 / リスト型（"5 Best ...")/ Before-After型）
2. サイズ・比率: 1000×1500px (2:3)
3. メインビジュアルの内容（写真/イラスト/商品写真のどれを使うか）
4. テキストオーバーレイ案（見出しコピー、最大10words）
5. 配色案（背景色、テキスト色、コントラスト確保の工夫）
6. ロゴ/ブランディング要素の配置位置

3パターンはそれぞれ異なる訴求軸（機能訴求/感情訴求/リスト訴求など）にしてください。
```

## 出力後のアクション

- 採用したブリーフを元にデザインツール（Canva等）または画像生成AIでPin画像を作成
- 完成画像を `pin_spec_sheet.md` に記録
