# プロンプト: Pinタイトル・説明文の作成

## 用途
Pinterest検索で見つけてもらうためのPinタイトル・説明文（Pinコピー）を作成する。

## プロンプト本文

```
あなたはPinterest SEOに強いコピーライターです。
以下の記事情報を元に、Pinのタイトルと説明文を作成してください。

【記事タイトル】: {タイトル}
【メインキーワード】: {キーワード}
【関連キーワード】: {関連キーワード}
【記事要約】: {要約}

以下を出力してください。
1. Pinタイトル案（100文字以内、キーワードを前方に含む）を5案
2. Pin説明文案（500文字以内、キーワードを自然に2〜3回含める、ハッシュタグ3〜5個を末尾に付与）を3案
3. Alt text案（画像の内容を説明、アクセシビリティ+SEO目的）

Pinterestのアルゴリズムは検索エンジン的な性質が強いため、
キーワードを不自然にならない範囲で積極的に含めてください。
誇大表現・断定的な効果効能の主張は避けてください。
```

## 出力後のアクション

- 採用したコピーを `pin_spec_sheet.md` に記録し、Pinterest投稿画面に反映
