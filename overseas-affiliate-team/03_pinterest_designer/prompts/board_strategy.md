# プロンプト: ボード構成・投稿計画

## 用途
アカウント全体のボード構成を設計し、新規Pinをどのボードに投稿するか計画する。

## プロンプト本文

```
あなたはPinterestアカウント運用戦略の専門家です。
以下の情報を元に、ボード構成と投稿計画を提案してください。

【アカウントのテーマ】: {サイト全体のテーマ、例: home decor for small apartments}
【既存ボード一覧】: {ボード名のリスト}
【今回投稿する記事のテーマ】: {テーマ}

以下を出力してください。
1. 今回のPinを投稿すべき既存ボード（優先順位付きで2〜3個）
2. 新規ボードを作るべきかの判断（作るべきならボード名・説明文案）
3. 週次投稿計画（1週間で何本、どのボードにどの頻度で投稿するか）
4. グループボード/コラボレーションの活用余地があるか

Pinterestのアルゴリズムはアカウント全体の一貫性（トピックの専門性）を評価するため、
テーマから逸脱しない範囲での提案をお願いします。
```

## 出力後のアクション

- 投稿計画を `pin_spec_sheet.md` およびチームカレンダーに反映
