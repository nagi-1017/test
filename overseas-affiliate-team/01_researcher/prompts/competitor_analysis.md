# プロンプト: 競合記事分析

## 用途
狙うキーワードで上位表示されている競合記事を分析し、差別化ポイントを見つける。

## プロンプト本文

```
あなたは競合分析に強いSEOリサーチャーです。
以下のキーワードで検索上位に表示される記事を分析してください（提供されたURL/テキストを元に分析すること。
推測で存在しないデータを作らないこと）。

【対象キーワード】: {キーワード}
【分析対象記事】:
1. {URL または記事テキスト1}
2. {URL または記事テキスト2}
3. {URL または記事テキスト3}

各記事について以下を出力してください。
1. 記事タイトルと構成（見出し一覧）
2. カバーしている内容・強み
3. 不足している情報・弱み（読者の疑問に答えきれていない点）
4. アフィリエイトリンクの配置方法（記事内/比較表/CTAボタン等）
5. 推定文字数・読みやすさ

最後に、これら3記事に共通して欠けている切り口を提案し、
自社記事で差別化するための構成案（見出し案）を作成してください。
```

## 出力後のアクション

- 差別化ポイントと構成案を `research_report_template.md` の「競合分析」欄に転記
- 英語ライターへの申し送り事項として明記する
