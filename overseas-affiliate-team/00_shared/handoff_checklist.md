# 役割間ハンドオフ・チェックリスト

各工程を終えて次の担当者に渡す前に、以下を満たしているか確認する。

## リサーチャー → 英語ライター

- [ ] ターゲットキーワード（メイン1 + 関連3〜5）を明記した
- [ ] 想定読者ペルソナを1〜2文で書いた
- [ ] 紹介する商品/サービスとアフィリエイトリンク（ASPリンク）を明記した
- [ ] 競合上位3記事の切り口・弱点をまとめた
- [ ] `research_report_template.md` の全項目を埋めた

## 英語ライター → Pinterestデザイナー

- [ ] 記事タイトル（複数案）を用意した
- [ ] 記事の要約（1〜2文、Pinコピーの元ネタ）を書いた
- [ ] CTA文言を明記した
- [ ] 公開URL（または公開予定日）を共有した
- [ ] FTC開示文が記事に入っていることを確認した

## Pinterestデザイナー → 改善分析官

- [ ] Pin画像のファイル名・投稿日・投稿先ボードを記録した
- [ ] Pinコピー（タイトル/説明文）を記録した
- [ ] リンク先URLがUTMパラメータ付きであることを確認した
- [ ] `pin_spec_sheet.md` を更新した

## 改善分析官 → リサーチャー（次サイクル）

- [ ] 好調だったキーワード/テーマを3つ以上挙げた
- [ ] 不調だったPin/記事とその推定原因を書いた
- [ ] 次サイクルで狙うべきテーマ・改善アクションを提案した
- [ ] `kpi_dashboard_template.md` を最新化した
