# プロンプト: A/Bテストの設計

## 用途
Pinデザイン、CTA、記事タイトルなどの改善施策をA/Bテストとして設計する。

## プロンプト本文

```
あなたはCRO（コンバージョン率最適化）に強いアナリストです。
以下の課題に対するA/Bテストを設計してください。

【テスト対象】: {例: Pinデザイン / CTA文言 / 記事タイトル / メタディスクリプション}
【現状の課題】: {例: Pin CTRが目標0.3%に対し0.15%で低迷}
【比較したい仮説】: {例: リスト型デザインの方がライフスタイル型より高CTRではないか}

以下を出力してください。
1. テストの目的とKPI（何を測定して勝敗を決めるか）
2. パターンA/パターンBの具体的な違い
3. サンプルサイズ・テスト期間の目安（統計的に意味のある差を検出するための最低限の目安）
4. テスト実施時に固定すべき変数（テーマ、投稿タイミング等）
5. 結果判定後のネクストアクション（勝ちパターンの横展開方法）

テストは1回につき1変数のみ変える設計にしてください。
```

## 出力後のアクション

- テスト設計をPinterestデザイナー/英語ライターと共有し実施を依頼
- 結果は次週の `performance_analysis.md` で評価
