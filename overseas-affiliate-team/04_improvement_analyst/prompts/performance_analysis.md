# プロンプト: 週次パフォーマンス分析

## 用途
Pin・記事・収益の週次データを分析し、傾向とインサイトを抽出する。

## プロンプト本文

```
あなたは海外アフィリエイトサイトのデータアナリストです。
以下の週次データを分析してください。

【期間】: {開始日}〜{終了日}
【Pinデータ】:
{Pinごとのインプレッション、クリック数、CTRを貼り付け}
【サイトデータ (GA4)】:
{記事ごとのセッション数、平均滞在時間、直帰率を貼り付け}
【収益データ (ASP)】:
{記事/リンクごとのクリック数、コンバージョン数、収益を貼り付け}

以下を出力してください。
1. 好調だったPin/記事トップ3とその要因（デザイン、コピー、テーマ等）
2. 不調だったPin/記事ワースト3とその推定原因
3. KPI（`00_shared/kpi_definitions.md` 参照: Pin CTR, 記事CVR, EPC等）の目標達成状況
4. 前週/前月からの変化トレンド
5. 各役割（リサーチャー/英語ライター/Pinterestデザイナー）への具体的な改善提案

提案には必ずどのデータに基づく判断かを明記してください。
```

## 出力後のアクション

- 結果を `kpi_dashboard_template.md` に転記
- 重要な提案は `weekly_report.md` のプロンプトでチーム向けレポートに整形
