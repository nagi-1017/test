# プロンプト: チーム向け週次レポート作成

## 用途
分析結果をチーム全員が読める形の週次レポートにまとめ、次サイクルへの申し送りを行う。

## プロンプト本文

```
あなたはチームリードに週次報告をするデータアナリストです。
以下の分析結果を元に、チーム全員（リサーチャー、英語ライター、Pinterestデザイナー）向けの
週次レポートを作成してください。

【今週のKPIサマリー】: {performance_analysis.md の結果を貼り付け}
【ファネル分析結果】: {funnel_diagnosis.md の結果を貼り付け（あれば）}
【実施中のA/Bテスト状況】: {ab_test_design.md の結果を貼り付け（あれば）}

以下の構成でレポートを作成してください。
1. サマリー（3行で今週の総括）
2. KPIハイライト（目標達成/未達を一目でわかる形で）
3. 好調だった施策とその要因
4. 改善が必要な施策と提案アクション（担当者別）
5. 次サイクルでリサーチャーが優先すべきテーマ・キーワード
6. 次サイクルで英語ライター/Pinterestデザイナーが意識すべきポイント

専門用語は最小限にし、非分析職のメンバーにも伝わる平易な言葉で書いてください。
```

## 出力後のアクション

- レポートを `kpi_dashboard_template.md` とともにチームに共有
- リサーチャーへの申し送り事項は次週月曜の着手前に伝達する（`00_shared/workflow.md` 参照）
