# プロンプト: ファネル離脱箇所の診断

## 用途
Pinインプレッションからコンバージョンまでのファネルのどこで離脱が多いかを特定する。

## プロンプト本文

```
あなたはファネル分析の専門家です。
以下のファネルデータを分析し、最も改善余地が大きいボトルネックを特定してください。

【ファネルデータ】:
- Pinインプレッション数: {数値}
- Pinクリック数: {数値}
- サイトセッション数: {数値}
- アフィリエイトリンククリック数: {数値}
- コンバージョン数（ASP計測）: {数値}

以下を出力してください。
1. 各段階の遷移率（インプレッション→クリック、クリック→セッション、セッション→リンククリック、リンククリック→CV）
2. 業界目安値との比較（分かる範囲で一般的なベンチマークと比較）
3. 最もボトルネックになっている段階の特定と、その原因仮説（3つ以上）
4. ボトルネック解消のための具体的な改善アクション（担当役割別に提案）
5. 改善アクション実施後、次に確認すべき指標

原因仮説は「デザイン」「コピー」「記事内容」「商品選定」「ページ速度/UX」など複数の観点から出してください。
```

## 出力後のアクション

- ボトルネック箇所に応じて該当役割（リサーチャー/英語ライター/Pinterestデザイナー）へ改善依頼を出す
