# プロンプト: メールシーケンスの作成

## 用途
記事誘導・リピート訪問を促すメールマガジン/ニュースレターのシーケンスを作成する。

## プロンプト本文

```
あなたはEメールマーケティングに強いコピーライターです。
以下の記事/商品を軸に、3通構成のメールシーケンスを作成してください。

【記事タイトル】: {タイトル}
【紹介商品】: {商品名}
【読者リストの状態】: {新規購読者 / 既存読者 のいずれか}

以下の構成で作成してください。
1. メール1（配信直後）: 記事への誘導、価値提供中心、CTAは控えめ
2. メール2（2〜3日後）: 商品の詳しい紹介、読者の悩みに共感する内容、CTAあり
3. メール3（5〜7日後）: 社会的証明（レビュー等）+ 最後のひと押しのCTA

各メールについて件名案（2つ）、プリヘッダー、本文（150〜250words）を出力してください。
CAN-SPAM法に準拠し、配信停止リンクの案内文言も含めてください。
```

## 出力後のアクション

- メール配信ツール（ConvertKit, Mailchimp等）にセットし、開封率/クリック率を改善分析官へ共有
