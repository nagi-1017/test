# プロンプト: CTA文言のバリエーション作成

## 用途
記事内・記事末尾に配置するCTA（購買行動を促す文言）を複数パターン作成し、A/Bテストに備える。

## プロンプト本文

```
あなたはコンバージョン率最適化(CRO)に強いコピーライターです。
以下の商品について、記事内で使うCTA文言を作成してください。

【商品/案件名】: {商品名}
【商品の一番のベネフィット】: {ベネフィット}
【読者が感じている悩み】: {ペインポイント}
【CTAを配置する場所】: {記事中盤の推薦文 / 記事末尾のまとめ / 比較表内 のいずれか}

以下のパターンで5案作成してください。
1. 緊急性を訴えるパターン（在庫/期間限定を示唆、誇張なし）
2. ベネフィット訴求パターン（読者が得られる結果を明示）
3. 好奇心を刺激するパターン
4. 社会的証明パターン（レビュー数/評価に言及）
5. シンプルな行動喚起パターン（"Check the price on Amazon" 等）

各CTAはボタンテキスト（3〜5words）とその前後に添える一文（1文）のセットで出力してください。
断定的な効果効能の主張、誇大表現は避けてください。
```

## 出力後のアクション

- 改善分析官と連携し、パフォーマンスが良かったCTAパターンを記録・蓄積する
