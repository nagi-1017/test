# プロンプト: SEO最適化（メタ情報・見出し）

## 用途
執筆済み記事のメタディスクリプション・タイトルタグ・見出し構成をSEO観点でチェック/改善する。

## プロンプト本文

```
あなたはSEOエディターです。以下の記事をレビューし、SEOを最適化してください。

【メインキーワード】: {キーワード}
【記事本文】:
{記事本文を貼り付け}

以下を出力してください。
1. SEOタイトルタグ案（55〜60文字、キーワードを前方に含む）を3案
2. メタディスクリプション案（150〜160文字、CTAを含む）を3案
3. 見出し(H2/H3)の改善提案（キーワードの含め方、読者の疑問に答える順序になっているか）
4. 内部リンクを追加すべき箇所の提案
5. キーワード出現率のチェック（不自然な詰め込みがないか、目安1〜2%）

改善が必要な場合は具体的な修正案（Before/After）を示してください。
```

## 出力後のアクション

- 採用したタイトル/メタディスクリプションをCMSに設定
- 見出し修正を記事本文に反映
